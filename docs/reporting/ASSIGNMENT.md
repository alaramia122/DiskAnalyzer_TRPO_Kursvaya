# Задание преподавателя

Ниже сохранена формулировка задания, предоставленная для проекта. Не заменять её пересказом в отчёте.

> Реализовать программу в виде оконного приложения, реализующего анализ дискового пространства файловой системы в виде круговой диаграммы.  
> Необходимо учесть вывод различных статистик на разных уровнях детализации - занимаемое пространство в абсолютном и относительном масштабе, вывод таблицей статистики по директориям, возможность выбрать статистику по конкретным типам файлов (бинарные, изображения и т.д.)  
> Язык программирования - C++.  
> Разрешается использовать любые доступные фреймворки для построения оконных приложений на C++.  
> Запрещается использовать готовые библиотечные решения.

## Интерпретация для реализации

Эта секция поясняет отражение задания в проекте; она не заменяет исходную формулировку.

- Оконное приложение реализовано на C++17 и Qt 5.
- Анализ файловой системы, построение дерева каталогов, классификация и агрегирование статистики реализованы в проекте.
- Qt используется как GUI/визуализационный фреймворк, а не как готовый анализатор дискового пространства.
- Относительные доли рассчитываются на основе агрегированных размеров выбранной области статистики.
- Категории определяются по расширению файла; это ограничение должно быть явно указано.
