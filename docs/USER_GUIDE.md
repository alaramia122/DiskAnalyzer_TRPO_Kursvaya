# Руководство пользователя Disk Analyzer

## 1. Назначение

Disk Analyzer анализирует выбранный каталог файловой системы и показывает распределение файлов по категориям, их количество и суммарный размер. Результаты отображаются в дереве каталогов, таблице статистики, таблице содержимого и круговой диаграмме.

Приложение предназначено для просмотра структуры и использования дискового пространства. Оно не удаляет, не перемещает и не изменяет анализируемые файлы.

## 2. Запуск

### Переносимая сборка Windows

1. Скачайте `DiskAnalyzer-Windows-x64.zip` со страницы [GitHub Releases](https://github.com/alaramia122/DiskAnalyzer_TRPO_Kursvaya/releases).
2. Распакуйте архив в каталог, в который у вас есть права записи.
3. Запустите `DiskAnalyzer_TRPO_Kursovaya.exe`.

Для запуска переносимого пакета не требуется устанавливать Visual Studio, компилятор или Qt отдельно. Если опубликованного релиза ещё нет, архив может быть доступен как артефакт в [GitHub Actions](https://github.com/alaramia122/DiskAnalyzer_TRPO_Kursvaya/actions); такие артефакты хранятся ограниченное время.

### Запуск из среды разработки

Откройте проект в совместимой среде CMake и выберите сборку с Qt 5, собранным под тот же компилятор. Для Windows с MSVC используйте Qt MSVC x64, а не вариант MinGW.

## 3. Проведение анализа

1. Введите путь к каталогу в поле пути или нажмите **«Обзор…»** и выберите каталог.
2. Нажмите **«Начать анализ»**.
3. Дождитесь завершения. Во время работы интерфейс должен оставаться отзывчивым; при необходимости воспользуйтесь командой отмены.
4. Просмотрите дерево каталогов и выберите нужный узел, чтобы увидеть относящуюся к нему статистику.
5. При анализе больших каталогов учитывайте сообщения об ошибках доступа и признак неполного результата.

Если корневой каталог недоступен или не существует, анализ не может быть выполнен корректно. Недоступность отдельных вложенных каталогов может привести к частичному результату, поскольку приложение не может учитывать данные, которые не удалось прочитать.

## 4. Как читать статистику

Для каталогов различаются следующие области:

- **Direct / непосредственно здесь** — файлы, находящиеся прямо в выбранном каталоге, без вложенных каталогов.
- **Subtree / вложенные каталоги** — файлы во вложенных каталогах, без файлов самого выбранного каталога.
- **Total / весь каталог** — сумма Direct и Subtree.

Статистика содержит количество файлов и суммарный размер, в том числе распределённые по категориям. Категория определяется по расширению файла; поэтому классификация может быть условной, если расширение не соответствует реальному содержимому.

Процент показывает долю размера категории относительно суммарного размера выбранной области. Для области с нулевым размером доли равны нулю.

## 5. Диаграмма

Круговая диаграмма отображает распределение **занимаемого размера**, а не количества файлов. Выберите область диаграммы в соответствующем списке:

- **«Только здесь»** — Direct;
- **«Вложенные каталоги»** — Subtree;
- **«Весь каталог»** — Total.

Точные значения категории доступны во всплывающих подсказках при наведении на сектор. При большом количестве категорий визуально небольшие сектора могут быть трудны для сравнения; в таком случае используйте таблицу статистики и подсказки.

## 6. Навигация и обновление

Выбирайте каталоги в дереве, чтобы просматривать их статистику без повторного полного сканирования файловой системы. Таблица содержимого показывает непосредственные элементы выбранного каталога.

Кнопка **«Обновить»** перечитывает список непосредственного содержимого выбранного каталога. Она **не пересчитывает** статистику всего дерева, сохранённую во время предыдущего анализа. Если после анализа файлы были добавлены, удалены или изменены, запустите полный анализ заново, чтобы получить актуальную агрегированную статистику.

## 7. Экспорт результатов

Используйте команды:

- **«Экспорт JSON…»** — сохранить структурированный результат в формате JSON;
- **«Экспорт TXT…»** — сохранить текстовое представление результата.

Выберите доступный каталог и задайте имя файла. Если запись невозможна из-за прав доступа или ошибки файловой системы, сохранение может завершиться неудачно. Не считайте экспортированный файл актуальным после изменения исходной файловой системы, пока не выполнен повторный анализ.

JSON предназначен для машинной обработки; TXT удобен для просмотра человеком.

## 8. Ошибки и ограничения

- Ошибки доступа к отдельным каталогам или файлам могут приводить к неполному результату.
- Символические ссылки на каталоги отображаются, но их цели не обходятся рекурсивно, чтобы избежать циклов и двойного учёта.
- Категория файла определяется по расширению. Анализ MIME-типа и сигнатуры содержимого не выполняется.
- Обновление локального списка содержимого не обновляет агрегированную статистику; для этого требуется полный повторный анализ.
- Время анализа и потребление памяти зависят от количества файлов, накопителя и доступности объектов файловой системы.

При сообщении об ошибке сохраните текст сообщения и повторите операцию на доступном тестовом каталоге. Не запускайте приложение от имени администратора только ради обхода ошибки без понимания последствий доступа к системным данным.
