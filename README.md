# Disk Analyzer — курсовой проект по ТРПО

Оконное приложение на C++17 и Qt 5 для анализа использования дискового пространства.

## Возможности

- Рекурсивный обход каталогов в отдельном рабочем потоке.
- Подсчёт количества и размера файлов по категориям.
- Раздельная статистика непосредственно в каталоге и в его поддереве.
- Дерево каталогов и таблица содержимого выбранного каталога.
- Круговая диаграмма распределения занятого пространства по категориям.
- Отображение абсолютных размеров и относительных долей в процентах.
- Отмена анализа, отображение прогресса и журнал ошибок файловой системы.
- Обновление списка содержимого выбранного каталога без повторного полного сканирования.
- Экспорт агрегированных результатов в JSON и TXT.
- Автоматические тесты и сборка через CMake/CTest и GitHub Actions.

## Технологии

- C++17, STL (std::filesystem, контейнеры, атомарные переменные, потоки).
- Qt 5: Core, Widgets, Charts.
- CMake 3.20 или новее.
- Основной алгоритм обхода и агрегации реализован в проекте; готовые анализаторы дискового пространства не используются.

## Сборка

Требуются компилятор C++17, CMake и Qt 5 с модулями Core, Widgets и Charts.

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug -DBUILD_TESTING=ON
cmake --build build --parallel
ctest --test-dir build --output-on-failure
```

В Windows следует использовать Qt, собранный для выбранного компилятора (например, MSVC). Не следует смешивать Qt для MinGW с компилятором MSVC или наоборот.

При сборке в Windows CMake выполняет post-build развёртывание Qt с помощью windeployqt, если утилита найдена рядом с используемой установкой Qt.

## Запуск и работа

1. Запустите приложение DiskAnalyzer_TRPO_Kursovaya.
2. Укажите каталог через поле пути или кнопку «Обзор…».
3. Нажмите «Начать анализ». Во время анализа доступна отмена; прогресс и ошибки показываются в окне.
4. Выберите каталог в дереве. Таблица статистики показывает число файлов и размер по категориям отдельно для текущего каталога и его поддерева, включая проценты.
5. Круговая диаграмма отображает доли занятого пространства; список над ней переключает область: «Только здесь», «Вложенные каталоги» или «Весь каталог».
6. Таблица содержимого показывает непосредственные элементы выбранного каталога. «Обновить» перечитывает только этот каталог; это не пересчитывает ранее полученную агрегированную статистику всего дерева.
7. Используйте «Экспорт JSON…» или «Экспорт TXT…» для сохранения результата анализа.

## Архитектура

Код разделён на четыре слоя:

- domain: категории, модели результатов и контракты scanner/classifier/aggregator.
- infrastructure: обход файловой системы, классификатор по расширению, агрегация, локальный кэш, чтение содержимого каталога и экспорт.
- application: конвейер анализа и контроллер жизненного цикла фоновой задачи.
- ui и visualization: оконный интерфейс и преобразование статистики для диаграммы.

Сканер заполняет direct-статистику и дерево каталогов; агрегатор вычисляет subtree-статистику снизу вверх. Символические ссылки на каталоги отображаются, но рекурсивно не обходятся, чтобы избежать циклов и двойного учёта. Кэш содержимого каталога используется для навигации и не является источником глобальной статистики.

Подробности и сценарии проверки см. в docs/ARCHITECTURE.md и docs/TESTING.md.
