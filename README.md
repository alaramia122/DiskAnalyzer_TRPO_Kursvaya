# Disk Analyzer — курсовой проект по ТРПО

Disk Analyzer — оконное приложение на C++17 для анализа использования дискового пространства. Программа обходит выбранный каталог, классифицирует файлы по расширению, рассчитывает статистику и представляет результаты в таблицах и круговой диаграмме.

- **Язык:** C++17
- **GUI:** Qt 5 (Core, Widgets, Charts)
- **Сборка:** CMake
- **Платформы:** Windows x64 и Linux x86_64
- **Пакеты:** Windows ZIP с развёрнутыми Qt runtime-библиотеками; Linux AppImage с упакованными Qt-библиотеками и плагинами

## Возможности

- Обход дерева каталогов в отдельном рабочем потоке.
- Классификация файлов по расширению.
- Подсчёт количества файлов и суммарного размера по категориям.
- Раздельная статистика файлов непосредственно в каталоге (**Direct**) и во вложенных каталогах (**Subtree**); полная статистика (**Total**) равна их сумме.
- Дерево каталогов, таблица содержимого выбранного каталога и круговая диаграмма распределения размера.
- Отображение абсолютных размеров и процентных долей.
- Прогресс, отмена анализа и журнал ошибок файловой системы.
- Навигация по результатам без повторного полного сканирования.
- Обновление списка непосредственного содержимого каталога.
- Экспорт агрегированных результатов в JSON и TXT.
- Автоматические тесты и сборка через GitHub Actions.

## Быстрый старт

1. Запустите приложение для своей платформы.
2. Укажите путь к каталогу или нажмите **«Обзор…»**.
3. Нажмите **«Начать анализ»**.
4. Выбирайте каталоги в дереве для просмотра статистики.
5. Переключайте область диаграммы: **«Только здесь»**, **«Вложенные каталоги»**, **«Весь каталог»**.
6. При необходимости экспортируйте результат через **«Экспорт JSON…»** или **«Экспорт TXT…»**.

Кнопка **«Обновить»** перечитывает список непосредственного содержимого выбранного каталога, но не пересчитывает агрегированную статистику всего дерева. После изменений файловой системы для актуализации общей статистики запустите анализ заново. Ошибки доступа могут сделать результат неполным.

Подробная инструкция: [руководство пользователя](docs/USER_GUIDE.md).

## Архитектура

Проект разделён на слои Domain, Infrastructure, Application, Visualization и UI. Сканер строит дерево и собирает Direct-статистику; агрегатор рассчитывает Subtree-статистику снизу вверх; контроллер управляет фоновой задачей; интерфейс отображает результаты и предоставляет команды пользователя.

Подробности: [архитектура проекта](docs/ARCHITECTURE.md).

## Сборка из исходного кода

Требуются CMake 3.20+, компилятор C++17 и Qt 5 с компонентами Core, Widgets и Charts.

### Linux (Ubuntu/Debian)

```sh
sudo apt update
sudo apt install build-essential cmake qtbase5-dev libqt5charts5-dev
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON
cmake --build build --parallel
ctest --test-dir build --output-on-failure
```

### Windows

Используйте Qt, собранный для выбранного компилятора (например, Qt MSVC x64 для MSVC). Не смешивайте Qt для MinGW и MSVC.

```powershell
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug -DBUILD_TESTING=ON
cmake --build build --config Debug --parallel
ctest --test-dir build -C Debug --output-on-failure
```

## Ограничения

- Категория определяется по расширению, анализ MIME-типа и сигнатуры содержимого не реализован.
- Символические ссылки на каталоги отображаются, но целевые каталоги повторно не обходятся.
- Недоступное содержимое нельзя достоверно включить в расчёт; ошибки доступа могут приводить к неполной статистике.
- Обновление списка каталога не заменяет полный повторный анализ.
